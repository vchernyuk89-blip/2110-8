# Ship Cont CAD CV 2.5 — проект сборки Windows EXE

**Ship Cont CAD CV 2.5** — настольное приложение для работы с контейнерным планом судна, файлами EDI/BAPLIE и Excel. Архив содержит исходный код и настройки сборки, а не готовый `.exe`.

## Что входит в версию 2.2

- Новое название программы, версия 2.2 и морская иконка с контейнеровозом.
- Обновлённое светлое морское оформление с тёмно-синими и бирюзовыми акцентами.
- Первая вкладка **«Проекты»** — создание и продолжение отдельных активных проектов судов.
- Автоматическое сохранение состояния активного проекта, включая контейнерные записи, данные судна, исходный файл и выбранный скелет. Проект обновляется по мере изменений и дополнительно сохраняется периодически.
- Вкладка **«Загрузки»** вместо «Главная / Проекты» для доступа к рабочим файлам.
- Вкладка **«Образцы»** — отдельное хранилище файлов; открытие EDI/Excel для работы создаёт рабочую копию, не перезаписывая файл образца.
- В режиме графики **Bay** — квадратные ячейки, тонкие чёрные контуры, тёмно-серый разделитель двух сторон секции и сохранённая чёрная граница между трюмом и палубой. Соответствующее оформление применяется и к экспорту графики.
- Сохранены основные возможности прежней версии: импорт и редактирование EDI/Excel, проверка, библиотека скелетов судов, план Tier/Bay, статистика и экспорт EDI/Excel/PDF/JPG/PNG.
- Пользовательские данные прежней версии при первом запуске переносятся из `Документы\CV Container Ship` в `Документы\Ship Cont CAD CV`, если новая папка ещё не существует. Исходная старая папка не удаляется.

## Сборка EXE через GitHub Actions

1. Распакуйте архив и загрузите его содержимое в корень репозитория GitHub, сохранив папку `.github/workflows`.
2. Откройте вкладку **Actions**.
3. Запустите workflow **Build Ship Cont CAD CV 2.5 for Windows** через **Run workflow**. При загрузке изменений, затрагивающих перечисленные в workflow файлы, сборка также может запускаться автоматически.
4. Дождитесь успешного завершения задания.
5. Внизу страницы запуска скачайте артефакт **`Ship_Cont_CAD_CV_v2.6_Windows_EXE`** и распакуйте его. Внутри должен находиться `Ship_Cont_CAD_CV_v2.6.exe`.

## Локальная сборка в Windows

Установите Python 3.10 или новее, откройте папку проекта и запустите `build_windows.bat`. Скрипт установит зависимости и создаст `dist\Ship_Cont_CAD_CV_v2.6.exe`.

## Рабочие данные

Рабочая папка приложения находится в `Документы\Ship Cont CAD CV`. В ней отдельно хранятся проекты-файлы, активные проекты, архив проектов, образцы, скелеты судов, экспорты, резервные копии, конфигурация и восстановление. Эти данные не должны храниться внутри EXE.

## Важные замечания

- В ZIP находятся исходники и сценарии сборки; готового EXE здесь нет.
- Синтаксис Python и тесты рендеринга можно проверить в среде разработки, но полноценное GUI-тестирование и проверку готового EXE необходимо выполнить в Windows после сборки.
- Перед использованием в рабочем процессе проверьте приложение на копиях своих EDI/Excel-файлов и подтвердите формат EDI требованиями принимающей стороны.


## Исправления 2.2: активные проекты

- Добавлена отдельная команда «Сохранить проект» для фиксации рабочего состояния независимо от экспорта EDI/Excel.
- Снимок проекта записывается атомарно через временный файл; при ошибке отображается явное сообщение, а не статус успешного сохранения.
- В снимке хранятся контейнеры, данные судна, исходные данные, выбранный скелет, режимы отображения и последняя вкладка.
- Открытие проекта проверяет структуру файла, восстанавливает данные редактора, плана и статистики.
- При закрытии приложения неудачное сохранение больше не скрывается: пользователь может отменить закрытие.
- Автосохранение показывает успешный статус только если запись файла проекта прошла успешно.

Данные активных проектов находятся в `Документы\Ship Cont CAD CV\ActiveProjects`. Версия 2.2 собрана как исходный проект; EXE необходимо пересобрать через GitHub Actions или `build_windows.bat`.


## Идентификатор судна в EDI (v2.4)
В окне «Данные судна» выберите IMO или ENI и укажите номер цифрами без префикса. IMO: 7 цифр с проверкой контрольной цифры. ENI: 8 цифр. IMO записывается в сегмент TDT с квалификатором `11`. Для ENI используется локальное соглашение `ZZZ`; перед отправкой рабочего BAPLIE подтвердите поддержку этого варианта у получателя.


## Изменения версии 2.5

- В Stowage Plan в режиме Bay над Row отображается только номер ряда.
- Справочник портов имеет поля «Страна», «Порт», «Код обозначения 5 символов» и «Код обозначения 2 символа». Справочник заполняется вручную; при выводе POD в Stowage Plan длинный код преобразуется по соответствию из справочника.
- Вкладка «Судна» принимает файлы скелетов Ship Creator CV (`.scv`) и сохраняет исходный `.scv` в библиотеке. Для графического плана автоматически создаётся совместимый Excel-файл с листом `POSITIONS`.

- Визуальное оформление печатного Stowage Plan по присланному образцу (квадратные активные ячейки, объединённое представление смежных BAY, подписи BAY/ROW/TIER) остаётся отдельной задачей следующей доработки и ещё не реализовано в этой версии.
